**Tech Stack**: Vite, React 19, Tailwind CSS v4, Framer Motion, TypeScript.

## Workflow: /plan
When generating a plan for a new piece of content or a new section (e.g., adding a Blog CMS or an expanded "Case Studies" data visualization):
1. **Analyze Requirements**: Align the feature with the goal of converting SMEs into leads.
2. **Design Blueprint**: Draft a split layout or interactive scroll strategy.
3. **Execution Run**: Build using Vite/React primitives.
4. **Validation Run**: Use the `browser_subagent` to grab desktop and mobile verification screenshots.
