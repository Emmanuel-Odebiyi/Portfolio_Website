# Frontend Design Skill

This skill ensures that all frontend outputs are visually stunning, premium, and professional. It prioritizes modern aesthetics over generic AI-generated defaults.

## Design Philosophy
- **Rich Aesthetics**: Avoid "default" looks. Use vibrant colors, dark modes, and glassmorphism.
- **Typography Excellence**: Use Google Fonts (e.g., Inter, Outfit, Playfair Display) rather than system defaults. Focus on hierarchy and readability.
- **Micro-interactions**: Incorporate subtle hovers, transitions, and entry animations to make the UI feel alive.

## Implementation Guidelines
### 1. Colors & Gradients
- Use curated HSL palettes.
- Prefer mesh gradients or subtle linear gradients for backgrounds and buttons.
- Ensure high contrast for text.

### 2. Layout & Composition
- Use generous white space to allow elements to breathe.
- Implement responsive grids with a focus on balanced proportions.
- Use rounded corners (e.g., `8px` to `24px`) for a modern, friendly feel.

### 3. Motion
- All interactive elements must have hover states.
- Use `ease-in-out` or `cubic-bezier` for transitions.
- Prefer CSS `transform` and `opacity` for animations.

## Review Checklist
- Is the design "wowed" at first glance?
- Are colors harmonious and premium?
- Is typography modern and well-structured?
- Are interactive elements responsive to mouse/touch?
