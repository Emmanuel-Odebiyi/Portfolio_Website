## Critical Priorities
### 1. Accessibility (CRITICAL)
- **Contrast**: Minimum 4.5:1.
- **Semantics**: Alt text, keyboard nav, ARIA labels.

### 2. Touch & Interaction (CRITICAL)
- **Sizing**: Minimum 44x44px touch targets.
- **Spacing**: 8px+ between interactive elements.
- **Feedback**: Immediate loading/active states.

### 3. Performance (HIGH)
- **Assets**: WebP/AVIF, lazy loading.
- **Metrics**: CLS < 0.1, fast LCP.

### 4. Layout & Navigation
- **Mobile-First**: Systematic breakpoints, no horizontal scroll.
- **Bottom Nav**: Max 5 items.
- **Predictability**: Consistent back behavior.

## Workflow
1. **Analyze**: Identify product type, audience, and keywords.
2. **Design System**: Define color, typography, and spacing tokens.
3. **Implement**: Prioritize accessibility and performance.
4. **Review**: Use the pre-delivery checklist for UX and UI quality.
